# Browser module (spike)

Generated by `../build_browser.ps1`; source wrapper is `grinsight_api.mjs`.

```text
grinsight_core.js    Emscripten ES module (MODULARIZE)
grinsight_core.wasm  Rust browser core, no LMDB/store
grinsight_api.mjs    small typed wrapper: abiVersion/headerHash/testAddress
package.json         type=module for Node selftest
selftest.mjs         Node vector check
```

Node check:

```powershell
node selftest.mjs
```

Expected:

```text
ABI=1
HEADER_HASH=2d71d7996a0cf2eda1c357eb11e713e1ef7930de5d293a839c4e4d40e37d3e1d
ADDRESS=tgrin1c2cdgqt0z0gcfxapxmt8xq25v8v2upynsn67gafvpkjmlzvqxrwqdwrqpa
S1_LEN=2052
```

`testS1Length` executes the real signing/transaction-building path in Wasm.
This is not yet the wallet API: `Storage`, `Transport`, sync and the gateway are
next. The module must be loaded in a Web Worker for the real UI; Emscripten
side-module/runtime integration is intentionally still a spike.
