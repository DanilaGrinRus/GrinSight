# fly-onion — Tor для платежей на адрес

Процесс, который отправляет платёж onion-сервису адреса `grin1…` и держит onion-сервис адреса своего кошелька. Спецификация ядра, раздел 7.25 (K151–K158).

## Что он делает и чего не делает

- Запускается процессом кошелька (`fly-paycore-host --onion <программа>`) для открытого профиля и говорит с ним через свой стандартный ввод и вывод (`paycore/onion-pipe`). В командной строке и окружении ему ничего не передаётся.
- Получает одну тайну — ключ адреса кошелька — и сам адрес; сверяет одно с другим и без совпадения не работает. Ключ нужен, потому что сервис адреса объявляется в Tor только этим ключом. Ключи сервиса живут в памяти; в файлы Tor не пишутся.
- Носит тела: запрос кошельку по чужому адресу и его ответ; запросы, пришедшие на свой сервис, и ответы, которые даёт кошелёк. Не читает их и ничего не решает.
- Файлы Tor держит в папке, которую ему дали (`onion-<экземпляр>` в профиле кошелька; внутри — `tor/cache`, `tor/state`). Портов на компьютере не открывает. Два кошелька на одном компьютере друг другу не мешают.

## Пределы

| Что | Сколько |
|---|---|
| Заголовок запроса или ответа | 8 КиБ |
| Тело запроса или ответа | 256 КиБ |
| Соединений с сервисом сразу | 8 |
| Запросов, ждущих ответа кошелька | 8 |
| Отправок сразу | 4 |
| Чтение запроса | 30 с |
| Ожидание ответа кошелька | 75 с |
| Одна отправка целиком | 120 с |
| Подъём Tor за одну попытку | 180 с, повтор через 30 с |

Запрос — только `POST /v2/foreign` с `Content-Length`; остальное получает отказ без тела.

## Проверка

```
cargo test                                   # 9 тестов без сети
powershell -File ..\run-live-onion-test.ps1  # живой Tor: объявить сервис и ответить самому себе
```

Живой прогон 24.11.2026 на Windows: сервис объявлен через 59 секунд после старта, запрос прошёл с первой попытки (`live-onion-test-20261124-1257.log`).

## Чего нет

- Мостов Tor и настроек Tor.
- Клиентской авторизации сервиса: соединиться может кто угодно; кто соединился — неизвестно.
- Обмен с чужими кошельками (grin-wallet, Grin++, GrinSight 0.4.2) вживую не проверен.
