# tor-bridges

Мосты Tor для трёх клиентов Tor кошелька: процесса цепи (`chain/tor`),
транспорта сообщений (`transport/tor`) и процесса адреса (`onion`).
Спецификация: раздел 7.26, правила K159–K164.

Что делает пакет:

- читает строки мостов, какими их выдаёт Tor (с ведущим словом `Bridge` или
  без него), и проверяет их: не больше 32 строк, строка не длиннее 2048 байт,
  весь текст не длиннее 60 000 байт, только печатные знаки ASCII; каждая
  строка должна разобраться тем же разбором, что в Arti; одна негодная строка
  отклоняет весь список;
- ставит мосты в конфигурацию Arti: мосты обязательны (напрямую Tor не
  выходит), программа транспортов одна — та, что лежит рядом с собственной
  программой процесса под постоянным именем (`lyrebird.exe`, `lyrebird`,
  на Android `liblyrebird.so`);
- транспорт без программы рядом — отказ до соединения.

Чего пакет не делает: не выбирает мосты (это делает пользователь в окне),
не запускает ничего сам (программу запускает Arti, когда мост её требует),
не печатает строки мостов ни в ошибках, ни в отладочном выводе.

Программа `lyrebird` здесь не собирается: она берётся из официального Tor
Expert Bundle скриптом `get-tor-bridge-programs.ps1` (SHA-256 архива
закреплён в скрипте, список сумм подписан разработчиками Tor Browser).

Тесты: `cargo test` — 8. Живой прогон через мосты: `run-live-bridges-test.ps1`
(obfs4, Snowflake и процесс адреса через obfs4; использует сеть).
