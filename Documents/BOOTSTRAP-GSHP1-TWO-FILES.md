# Два файла GSHP1 на чистом профиле

Здесь зафиксирован прогон первоначального автономного варианта. Его отрицательный контроль относится к явно выбранному режиму genesis. На пустом профиле обычный запуск использует встроенную точку. В сборке 0.4.7A с импортом получатель может явно выбрать два файла в интерфейсе, проверить их и сохранить точку как начало своей истории. Процедура описана в [инструкции для получателя](ADR-LOCAL-CHECKPOINT.md).

Отрицательный контроль для следующего этапа автономного старта. Использованы настоящая точка Mainnet на высоте 4 115 520 и её выборочное доказательство из исходников 0.4.7A. Объём пары — 8 294 407 байт (9 391 байт точки и 8 285 016 байт доказательства).

| Проверка в отдельном процессе | Наблюдение |
|---|---|
| Провайдер получает пару, собирает и повторно проверяет публикацию | `research candidate main 4115520 … (GSHP1 sample; freshness unknown)` |
| Та же пара для Floonet, изменённая работа точки, обрезанное доказательство | Каждый вариант отклонён до публикации манифеста |
| У нового экземпляра `fly-chain` в каталоге данных только эта точка под прежним именем `own-point.json` и файл `history.proof`; единственный пир — зарезервированный локальный порт без слушателя | По истечении диагностического срока высота 0, хеш соответствует genesis Mainnet, журнал содержит один кадр, актуальность неизвестна. Два исходных файла сохранились |

В 0.4.7A отдельная утилита проверки выборки и менеджер начала истории имеют разные обязанности. Менеджер не имеет процедуры импорта GSHP1 для установки доверенной точки. Этот прогон проверяет сегодняшнюю границу, а не криптографическую невозможность будущей конструкции. Новая конструкция должна отдельно показать положительный результат на чистом профиле с корректной парой, не обращаться за старыми заголовками и по-прежнему отклонять несогласованные данные. Актуальность вершины требует своей проверки.

Из корня исходников 0.4.7A:

~~~powershell
python -B Source/tools-audit/test_two_file_gshp1.py --provider <grin-proof-provider.exe> --chain <fly-chain.exe>
~~~

Нужны Python 3 и исполняемые файлы версии 0.4.7A. Скрипт создаёт и убирает временный каталог. Пользовательский профиль не принимается как аргумент.
