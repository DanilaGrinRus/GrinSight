# GrinSight 0.2.0 — что в релизе

«Revelio for your coins» 🐻 — лёгкий кошелёк Grin, который сам проверяет цепочку.

## Файлы

| Файл | Для чего |
|---|---|
| `GrinSight-0.2.0-windows-x64-setup.exe` | **установщик** для Windows 10/11 x64, подписанная контрольная точка mainnet внутри; права администратора не нужны |
| `GrinSight-0.2.0-android-arm64.apk` | Android 7+ (предварительная сборка), та же подписанная контрольная точка внутри |
| `GrinSight-0.2.0-CHECKPOINT.txt` | какая подписанная контрольная точка mainnet внутри всех пакетов этой версии (высота, хэш, SHA-256) |
| `GrinSight-0.2.0-source.zip` | исходники: ядро, Tor/GlauxNet, C API, приложение на Flutter, скрипты сборки (без данных пользователя и секретов) |
| `SHA256SUMS.txt` | контрольные суммы всех файлов |

Документы (как это работает, математика, схемы, зависимости) — в репозитории, папка `Documents`.

**Проверьте файл перед запуском** (PowerShell):

```powershell
Get-FileHash .\GrinSight-0.2.0-windows-x64-setup.exe -Algorithm SHA256
```

Хеш должен совпасть со строкой этого файла в `SHA256SUMS.txt`.

## Что нового в этой версии

- **Проверить контрольную точку самому — до входа в кошелёк.** «Проверить сам» скачивает
  все заголовки от первого блока у независимых узлов, проверяет каждый, строит свежую точку
  и сверяет, что поставочная лежит на той же цепочке. Кошельки сами переходят на неё.
  Так кошелёк работает даже с устаревшей поставочной точкой.
- **Устаревание точки больше не ломает кошелёк.** Раньше новый кошелёк переставал
  открываться примерно через две недели после выпуска точки, теперь — около года;
  политика релизов — точка не старше 90 дней.
- **Баланс показывается как доказанный только честно:** файл баланса проверяется по MAC
  вашей seed-фразой и должен описывать ту же вершину (высоту и хэш блока), что и
  доказательство; пропажа журнала резервов тоже видна.
- **История после reorg:** блоки недавних платежей перепроверяются при каждом обновлении;
  без перепроверки платёж показывается «не перепроверен», а не «подтверждён».
- **Seed-фраза из 12, 18 или 24 слов** (совместима с grin-wallet и Grin++), проверка двух
  случайных слов; показ seed и смена пароля; переименование кошелька.
- **Интерфейс:** окно «Проверка» объединяет статус, контрольную точку и свой пир;
  компактные «Отправить» и «Получить», QR из файла-картинки, входящие на главном экране,
  поиск и свои имена в адресной книге, Enter для входа.
- **Режим «Пощупать будущее»** честно помечен как эксперимент: проверка через
  header-proof ещё не подключена, баланс проверяется обычным путём.

## Что внутри

- **Проверяющий лёгкий кошелёк:** заголовки от нескольких публичных пиров (PoW,
  сложность, связность, самая тяжёлая цепочка, подтверждённая пирами из разных сетей),
  состояние непотраченных выходов из PIBD-сегментов со сверкой с `output_root`, каждый
  блок до вершины — со сверкой `output_root` / `kernel_root`. Ни ноды, ни доверенного сервера.
- **Подписанная контрольная точка:** mainnet стартует с точки, подписанной ключом,
  вшитым в кошелёк (высота 4,098,960); откат к старому релизу запрещён. Плавающая
  контрольная точка делает последующие обновления короткими (секунды).
- **Ключи не покидают устройство:** фраза (12, 18 или 24 слова) зашифрована паролем (scrypt +
  ChaCha20-Poly1305) и передаётся ядру только в памяти.
- **Платежи:** отправка, приём, счета (slatepack), рассылка сразу после финализации,
  подтверждение по kernel в блоке проверенной цепочки (с проверкой reorg), доказательство
  платежа (подпись получателя).
- **Tor-переводы совместимы с grin-wallet и Grin++:** первый перевод от нового
  отправителя подтверждается вручную.
- **Баланс по частям:** доступно / зарезервировано / входит / созревает.
- **GlauxNet (Windows):** пока кошелёк открыт, работает ваш собственный зашифрованный
  почтовый ящик — локальный шлюз «храни-и-передай», опубликованный как ваш onion в Tor:
  платежи и счета доходят до вас без чужих серверов. Включён по умолчанию, отключается
  в настройках; запасной сервер GlauxNet (по желанию) используется, только если Tor
  не запустился. Автоматическая доставка slatepack контактам, политика автоприёма.

## Проверено на живых сетях

- **Mainnet:** пять транзакций, отправленных из кошелька, подтвердились в блоках
  mainnet с 4 100 766 по 4 100 860.
- **Floonet:** установка, обновления и доказанный баланс; перевод 1 tGRIN между двумя
  кошельками через приложение (S1 → S2 → финализация → рассылка), подтверждён на глубине
  14 с доказательством платежа.
- Приёмочные тесты: ядро, проверки, точки сбоя платежей, reorg, фаззинг, уязвимости
  зависимостей, сквозной тест сервиса кошелька.

## Установка

- **Windows:** запустить установщик, затем GrinSight из меню «Пуск». Данные кошельков:
  `%APPDATA%\GrinSight` (при удалении программы не стираются).
  Первое «Обновить» строит проверенное состояние (mainnet: около 670 МБ, 10–20 минут),
  дальше — секунды.
- **Android (предварительная сборка):** установить APK (разрешить установку из этого
  источника). Первое обновление — по Wi‑Fi.

## Известные ограничения

- Поставочная точка старше ~300 дней: кошелёк попросит построить свою («Проверить сам»).
- Режим «Пощупать будущее» (header-proof) пока экспериментальный и не влияет на проверку.
- Веб-версия (PWA) не входит в этот релиз.
- Android: доставка через Tor есть не в каждой сборке; slatepack можно передавать текстом.
- Видимая цепочка — та, что дали пиры и проверил кошелёк: несколько пиров из разных
  сетей уменьшают, но не исключают риск изоляции нечестными пирами
  (см. `MATHEMATICS_RU.md`).
- Независимого аудита безопасности пока нет.
