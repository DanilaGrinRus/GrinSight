# GrinSight 0.4.1-ThxWiesche — что в релизе

«Revelio for your coins» 🐻 — лёгкий кошелёк Grin, который сам проверяет цепочку.

## Файлы

| Файл | Для чего |
|---|---|
| `GrinSight-0.4.1-ThxWiesche-windows-x64-setup.exe` | **установщик** для Windows 10/11 x64, подписанная контрольная точка mainnet внутри; права администратора не нужны |
| `GrinSight-0.4.1-ThxWiesche-android-arm64.apk` | Android 7+ (предварительная сборка), та же подписанная контрольная точка внутри |
| `GrinSight-0.4.1-ThxWiesche-linux-amd64.deb` | **Debian/Ubuntu** amd64, пакет `.deb`, та же подписанная контрольная точка внутри; приложение, ярлык и Tor включены |
| `GrinSight-0.4.1-ThxWiesche-CHECKPOINT.txt` | какая подписанная контрольная точка mainnet внутри всех пакетов этой версии (высота, хэш, SHA-256) |
| `GrinSight-0.4.1-ThxWiesche-source.zip` | исходники: ядро, Tor/GlauxNet, C API, приложение на Flutter, скрипты сборки (без данных пользователя и секретов) |
| `SHA256SUMS.txt` | контрольные суммы всех файлов |

Документы (как это работает, математика, схемы, зависимости) — в репозитории, папка `Documents`.

**Проверьте файл перед запуском** (PowerShell):

```powershell
Get-FileHash .\GrinSight-0.4.1-ThxWiesche-windows-x64-setup.exe -Algorithm SHA256
```

Хеш должен совпасть со строкой этого файла в `SHA256SUMS.txt`.

## Что нового в этой версии

- **Проверка цепочки — как у полного узла (по внешнему ревью).** При сборке состояния из архива
  кошелёк теперь проверяет rangeproof каждого непотраченного выхода, подпись каждого ядра,
  kernel_root и эмиссию (нет «напечатанных» монет); без сегментов ядер — отказ, а не
  продолжение. В каждом блоке проверяется созревание coinbase (1440 блоков), как в Grin.
  Состояние от прошлых версий один раз пересобирается заново (первая синхронизация дольше).
- **Новый главный экран.** Баланс и статус проверки — в одной карточке (одна строка
  «ДОКАЗАН / НЕ ПРОВЕРЕНО» с «Обновить»); суммы входящих зелёные только после
  подтверждения. «Мои реквизиты»: адрес кошелька и фраза для поиска в Nostr копируются
  нажатием. Журнал предупреждений и ошибок: у каждой записи «?» — что это значит
  и что сделать. «Входящие slatepack» и «Сообщения» — рядом; колонки выровнены.
- **Tor честнее:** «процесс запущен» и «подключён к сети» — разные состояния; пока Tor
  не подключён, рядом «Настройки мостов». Tor включается и выключается отдельно от
  мессенджера и закрывается вместе с приложением (не остаётся висеть).
- **Доставка платежей — явные кнопки** Tor / Вручную / GlauxMail. «Вручную» показывает
  все slatepack последнего платежа (S1, S2, I1, I2) с «Скопировать» и «Показать».
- **Мессенджер можно выключить целиком;** каналы переписки — окно с кнопками Tor,
  I2P напрямую, Nostr через I2P, Nostr напрямую и понятными свойствами каждого
  (виден ли IP, нужен ли сервер, доставка, если собеседник не в сети).
- **Шапка:** все действия — значками в одну линию, ничего не спрятано; «Пощупать
  будущее» — переключателем. В настройках — только название, пароль и seed-фраза.
- **Стиль:** медведь в шестиграннике, GrinSight, «Revelio for your coins»; монохромная
  тема «Ч/Б» в духе grin.mw (выбор прямо на экране входа), логотип и кнопка под
  курсором остаются чёрно-золотыми.
- **Исправления:** вход в кошельки старого формата («malformed»); «another wallet operation
  is running» при отправке после «Обновить»; «Обновить» без своей контрольной точки;
  понятная ошибка, если вместо slatepack вставлен адрес.

## Что внутри

- **Проверяющий лёгкий кошелёк:** заголовки от нескольких публичных пиров (PoW,
  сложность, связность, самая тяжёлая цепочка, подтверждённая пирами из разных сетей),
  состояние непотраченных выходов из PIBD-сегментов со сверкой с `output_root`, каждый
  блок до вершины — со сверкой `output_root` / `kernel_root`. Ни ноды, ни доверенного сервера.
- **Подписанная контрольная точка:** mainnet стартует с точки, подписанной ключом,
  вшитым в кошелёк (высота 4,098,960); откат к старому релизу запрещён. Плавающая
  контрольная точка делает последующие обновления короткими (секунды).
- **Ключи не покидают устройство:** фраза (12, 18 или 24 слова) зашифрована паролем (scrypt +
  ChaCha20-Poly1305) и передаётся ядру только в памяти.
- **Платежи:** отправка, приём, счета (slatepack), рассылка сразу после финализации,
  подтверждение по kernel в блоке проверенной цепочки (с проверкой reorg), доказательство
  платежа (подпись получателя).
- **Tor-переводы совместимы с grin-wallet и Grin++:** первый перевод от нового
  отправителя подтверждается вручную.
- **Баланс по частям:** доступно / зарезервировано / входит / созревает.
- **GlauxNet (Windows):** пока кошелёк открыт, работает ваш собственный зашифрованный
  почтовый ящик — локальный шлюз «храни-и-передай», опубликованный как ваш onion в Tor:
  платежи и счета доходят до вас без чужих серверов. Включён по умолчанию, отключается
  в настройках; запасной сервер GlauxNet (по желанию) используется, только если Tor
  не запустился. Автоматическая доставка slatepack контактам, политика автоприёма.

## Проверено на живых сетях

- **Mainnet:** пять транзакций, отправленных из кошелька, подтвердились в блоках
  mainnet с 4 100 766 по 4 100 860.
- **Floonet:** установка, обновления и доказанный баланс; перевод 1 tGRIN между двумя
  кошельками через приложение (S1 → S2 → финализация → рассылка), подтверждён на глубине
  14 с доказательством платежа.
- Приёмочные тесты: ядро, проверки, точки сбоя платежей, reorg, фаззинг, уязвимости
  зависимостей, сквозной тест сервиса кошелька.

## Установка

- **Windows:** запустить установщик, затем GrinSight из меню «Пуск». Данные кошельков:
  `%APPDATA%\GrinSight` (при удалении программы не стираются).
  Первое «Обновить» строит проверенное состояние (mainnet: около 670 МБ, 10–20 минут),
  дальше — секунды.
- **Android (предварительная сборка):** установить APK (разрешить установку из этого
  источника). Первое обновление — по Wi‑Fi.
- **Linux (Debian/Ubuntu):** `sudo apt install ./GrinSight-0.4.1-ThxWiesche-linux-amd64.deb`,
  затем GrinSight из меню приложений. Данные кошельков: `~/.grinsight`. Первое
  «Обновить» — те же 10–20 минут, дальше — секунды.

## Известные ограничения

- Монохромная тема пока не запоминается: после перезапуска приложение снова цветное.
- «Выключить мессенджер» скрывает контакты и переписку в интерфейсе; служба переписки при этом не останавливается.
- Полные приёмочные тесты ядра для этой версии не перезапускались; модульные тесты ядра (в т.ч. новые на созревание coinbase, эмиссию и закрытый отказ) — PASS; виджет-тесты приложения 148/148 PASS.
- Поставочная точка старше ~300 дней: кошелёк попросит построить свою («Проверить сам»).
- Режим «Пощупать будущее» (header-proof) пока экспериментальный и не влияет на проверку.
- Веб-версия (PWA) не входит в этот релиз.
- Android: доставка через Tor есть не в каждой сборке; slatepack можно передавать текстом.
- Видимая цепочка — та, что дали пиры и проверил кошелёк: несколько пиров из разных
  сетей уменьшают, но не исключают риск изоляции нечестными пирами
  (см. `MATHEMATICS_RU.md`).
- Независимого аудита безопасности пока нет.
