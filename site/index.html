Что внутри

Кошелёк, который проверяет,
а не просит доверия

GrinSight не заменяет ноду — он проверяет то, что получил от публичных пиров. Каждый слой можно проследить до математики.

01

Заголовки и PoW

Несколько публичных пиров, проверка proof of work, сложности и связности. Выбирается самая тяжёлая цепочка, подтверждённая пирами из разных сетей.

02

Состояние выходов

Непотраченное состояние собирается из PIBD-сегментов и сверяется с output_root из проверенного заголовка.

03

Каждый новый блок

Блоки до вершины проверяются по output_root / kernel_root; подтверждение платежа — по kernel в блоке проверенной цепи, с проверкой reorg.

04

Ключи не уходят

Фраза шифруется паролем (scrypt + ChaCha20-Poly1305) и передаётся ядру только в памяти. Приложение не хранит её в открытом виде.

05

Баланс по частям

Доступно, зарезервировано, входит и созревает — видно, что можно тратить прямо сейчас, а что ещё ждёт подтверждения.

06

GlauxNet и Tor

На Windows собственный шифрованный ящик работает, пока открыт кошелёк: локальный store-and-forward gateway как onion. Tor-обмен платежами и счетами работает и в Linux-сборке.

Сверьте SHA-256

Скачайте SHA256SUMS.txt и сравните: Windows — Get-FileHash, Linux — sha256sum. Хеш должен совпасть со строкой вашего файла.

Windows — запустите setup.exe; Linux — sudo apt install ./GrinSight-0.2.0-linux-amd64.deb; Android — установите APK, разрешив источник.

Постройте состояние

Первое «Обновить» скачает около 670 МБ и проверит цепочку за 10–20 минут. Дальше обновления — секунды.

Доверие без лозунгов

Что именно проверяется

Коротко: заголовки → состояние выходов → баланс. Полная математика — в документах.

Честно об ограничениях

Нет независимого аудита безопасности. Видимая цепочка — та, что дали пиры: несколько сетей уменьшают, но не исключают изоляцию. Поставочная точка не старше 90 дней; если она старше ~300 дней, кошелёк предложит построить свою («Проверить сам»).
